# Password Checker 🔐

Validador de palavras-passe desenvolvido em Python.

## Funcionalidades

- Verificação do comprimento mínimo de 8 caracteres.
- Identificação de letras maiúsculas.
- Identificação de letras minúsculas.
- Verificação da presença de números.
- Identificação de caracteres especiais.
- Cálculo da pontuação.
- Classificação da palavra-passe: Fraca, Média ou Forte.

## Tecnologias utilizadas

- Python 3
- Regular Expressions (`re`)
- GetPass
- Dicionários e funções.

## Como executar

1. Instala o Python 3.
2. Clona este repositório.
3. Executa:

```bash
python main.py
```
